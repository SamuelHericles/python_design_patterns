# 📐 Design Patterns — Gang of Four (GoF)

Este repositório contém exemplos práticos dos **23 padrões de projeto** catalogados pelo **GoF (Gang of Four)** no livro clássico *"Design Patterns: Elements of Reusable Object-Oriented Software"*, todos implementados em **Python**.

---

## 📦 Padrões Criacionais (Creational)

Lidam com a criação de objetos, tornando o sistema independente de como seus objetos são criados, compostos e representados.

| Padrão | Descrição |
|---|---|
| **Abstract Factory** | Cria famílias de objetos relacionados |
| **Builder** | Constrói objetos complexos passo a passo |
| **Factory Method** | Cria objetos sem especificar a classe exata |
| **Prototype** | Clona objetos existentes |
| **Singleton** | Garante uma única instância global |

---

## 🏗️ Padrões Estruturais (Structural)

Lidam com a composição de classes e objetos para formar estruturas maiores e mais flexíveis.

| Padrão | Descrição |
|---|---|
| **Adapter** | Adapta uma interface incompatível |
| **Bridge** | Separa abstração de implementação |
| **Composite** | Trata objetos individuais e composições uniformemente (parte-todo) |
| **Decorator** | Adiciona responsabilidades dinamicamente |
| **Facade** | Interface simplificada para um subsistema complexo |
| **Flyweight** | Compartilha objetos para economizar memória |
| **Proxy** | Substituto ou placeholder para outro objeto |

---

## 🔄 Padrões Comportamentais (Behavioral)

Lidam com a comunicação e responsabilidades entre objetos.

| Padrão | Descrição |
|---|---|
| **Chain of Responsibility** | Passa uma requisição por uma cadeia de handlers |
| **Command** | Encapsula uma requisição como objeto |
| **Iterator** | Acessa elementos de uma coleção sequencialmente |
| **Mediator** | Centraliza a comunicação entre objetos |
| **Memento** | Salva e restaura o estado de um objeto |
| **Observer** | Notifica dependentes sobre mudanças de estado |
| **State** | Muda o comportamento conforme o estado interno |
| **Strategy** | Define algoritmos intercambiáveis |
| **Template Method** | Define o esqueleto de um algoritmo, delegando etapas às subclasses |
| **Visitor** | Opera sobre elementos de uma estrutura sem alterar suas classes |

---

## 🚀 Como executar

Certifique-se de ter o **Python 3.8+** instalado e execute:

```bash
python [pasta]\[padrão_de_projeto]\main.py
```

Todos os 23 padrões serão demonstrados no terminal com exemplos funcionais.
